# Study MBBS Abroad - Landing Page 🌍

A **responsive landing page** designed for students interested in studying MBBS abroad. This project is built using **HTML, Tailwind CSS, and JavaScript**, offering a modern, fast, and SEO-friendly experience.

---

## 🚀 Live Demo
🔗 **Live URL:** [Study MBBS Abroad Landing Page](https://landing-page-three-gray-40.vercel.app)

---

## 📜 Features

✅ **Fully Responsive Design** (Mobile & Desktop Friendly)  
✅ **Top MBBS Destinations Listed** (Russia, Uzbekistan, Kazakhstan, Philippines, Georgia, Kyrgyzstan, Egypt)  
✅ **Admission Process & Eligibility Details**  
✅ **Lead Generation Form with Form Validation**  
✅ **SEO Optimized with Fast Loading Speed**  
✅ **Google Analytics & Facebook Pixel Integrated**  
✅ **Smooth Scroll & Call-to-Action (Apply Now)**

## 🛠️ Installation & Setup Instructions

### **1️⃣ Clone the Repository**
If you want to work with this project on your local machine, open a terminal and run:

# Clone the repository
git clone https://github.com/Bhargavi9391/Landing-page.git

# Navigate to project directory
cd landing-page

### **2️⃣ Open the Project**
Since this is a static landing page, no additional setup is required. You can directly open `index.html` in any browser to preview the page.

### **3️⃣ Deploy on Vercel**
If you haven't deployed yet, follow these steps:

1️⃣ **Install Vercel CLI** (if not installed):
```sh
npm install -g vercel
```

2️⃣ **Login to Vercel**
```sh
vercel login
```

3️⃣ **Deploy**
```sh
vercel
```

4️⃣ Vercel will generate a **Live URL** where your project is hosted.
